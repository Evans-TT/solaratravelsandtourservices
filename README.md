# Solara Travel and Tours Services

Premium travel and visa-assistance website for `solaratravelsandtourservices.com`.

## Local development

```bash
npm install
npm run dev -- --port 3000
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

The static website is generated in `dist/client`. The prepared GitHub Pages package is stored in `docs`, with the custom domain in `CNAME` and `.nojekyll` included for the `_next` assets.

## Contact routing

All application and enquiry actions open WhatsApp for `+27 61 201 7515` with a pre-filled message matching the selected service or visa.
